## Kia ora, I'm Chandan Kumar

I'm working at the intersection of **data science, AI engineering, research automation, and public-interest health data discovery**.

My current focus is **NeuroNZ**: a neurological data and resource catalogue for Aotearoa New Zealand. The project connects curated catalogue records, Zotero evidence management, automation pipelines, and a WordPress public discovery layer.
